# @james-tanuwidjaja/vue3-components

A reusable **Vue 3** component library — single `createJt()` plugin, precompiled CSS, runtime theming, built-in form validation, and a self-built documentation site.

📖 **[Documentation & live examples →](https://james-tanuwidjaja.github.io/vue3-components-library/)**

```bash
npm install @james-tanuwidjaja/vue3-components
```

## Components

**Form inputs:** `JtButton` · `JtTextField` · `JtTextarea` · `JtNumberField` · `JtMoneyField` · `JtSelect`

**Selection controls:** `JtCheckbox` · `JtSwitch` · `JtRadioGroup`

**Pickers:** `JtDatePicker` · `JtDateTimePicker`

**Data:** `JtDataTable` · `JtSmartTable`

**Feedback:** `JtDialog` · `JtDialogProvider` · `JtTooltip` · `JtSkeleton`

**Forms:** `JtForm`

**Layout:** `JtLayout` · `JtHeader` · `JtSidebar` · `JtFooter`

See the [docs site](https://james-tanuwidjaja.github.io/vue3-components-library/) for installation, theming, API tables, and live examples.
